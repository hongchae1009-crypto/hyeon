알켄의 반응 — 다이하이드록시화의 입체화학

2015전공A 서술형 3번8. 알카인[5점]

2-butyne → cis-2-butene → syn/anti 다이하이드록시화 (메소 vs 라셈)

문제 요지2-butyne —(H₂, Lindlar)→ A → B (meso 다이올) / C (B와 부분입체이성질체). [시약] H⁺/H₂O, CH₃CO₃H, OsO₄, CrO₃, NaHSO₃/H₂O, O₃ 중 선택. A 구조, A→B·A→C 시약, 각 중간체의 입체 구조, 입체구조가 B·C처럼 된 이유.
모범답안A: cis-2-butene
A → B: OsO₄, NaHSO₃/H₂O — 중간체: 고리형 오스뮴산 에스터 (두 C–O가 같은 면) → syn 첨가 → meso-2,3-butanediol
A → C: CH₃CO₃H, H⁺/H₂O — 중간체: cis-2,3-dimethyloxirane → 양성자화 에폭사이드 → H₂O가 반대 면에서 SN2형 공격 → anti 첨가 → (2R,3R) + (2S,3S) 라셈 혼합물
핵심 개념 · 공식
  • Lindlar 촉매(Pd/CaCO₃, 피독): 알카인 → cis-알켄 (syn 수소 첨가)
  • OsO₄: 협동적 [3+2] 고리 첨가 → 고리형 오스뮴산 에스터 → syn 다이올 (NaHSO₃로 Os–O 절단)
  • 과산 에폭시화(syn, 입체 특이) + 산 촉매 개환(뒷면 공격) → anti 다이올
  • cis-알켄 + syn → meso / cis-알켄 + anti → 라셈 (trans-알켄이면 반대)
풀이 과정 · 메커니즘

B (syn): OsO₄가 C=C의 한쪽 면에 동시에 결합하여 5원 고리 오스뮴산 에스터를 만든다. NaHSO₃/H₂O로 Os–O 결합이 끊겨도 C–O 결합은 유지되므로 두 OH가 같은 면에 도입된다. cis-알켄에 syn 첨가 → 분자 내 거울면 → meso.

C (anti): 과산이 한쪽 면에서 산소를 전달해 cis-에폭사이드(meso)를 만든다. H⁺가 에폭사이드 O를 양성자화하면, H₂O가 O의 반대 면에서 C를 공격(뒷면 공격, 반전)한다. 두 탄소는 동등하므로 C2 공격과 C3 공격이 같은 확률로 일어나 거울상 이성질체 (2R,3R)와 (2S,3S)가 1:1로 생긴다 → 라셈, B와는 부분입체이성질체.

예상 의문점 Q&A

Q. O₃나 CrO₃는 왜 안 되나요?

A. O₃는 C=C를 절단(오존 분해, 아세트알데하이드 2분자)하고, CrO₃는 산화제로 다이올을 만들지 않습니다.

Q. C는 광학 활성인가요?

A. 각 분자는 키랄이지만 두 거울상이 1:1로 생긴 라셈 혼합물이므로 광학 비활성입니다.

Q. trans-2-butene으로 같은 반응을 하면?

A. 반대가 됩니다: OsO₄ → 라셈, 과산/H₃O⁺ → meso. “cis + syn = meso, trans + anti = meso”로 기억하면 편합니다.

참고 해설 비교 · 보강

정답 일치: A = cis-2-butene, A → B: OsO₄ → NaHSO₃/H₂O(고리형 오스뮴산 에스터 경유 syn 첨가 → meso), A → C: CH₃CO₃H → H⁺/H₂O(cis-에폭사이드 → 양성자화 → H₂O의 anti 고리 열림 → (2R,3R)+(2S,3S) 라세미)로 참고 해설과 같다.

참고 해설의 흐름: 중간체를 입체구조로 그리는 것이 핵심이다 — ① 오스뮴산 에스터: 두 O가 C=C의 같은 면에 결합한 5원 고리(두 CH₃·두 H가 같은 쪽) ② cis-2,3-dimethyloxirane과 그 양성자화 에폭사이드(O–H⁺). H₂O가 C2 또는 C3를 O의 반대쪽에서 공격하면 각각 (2R,3R)과 (2S,3S)가 되며, 두 탄소가 동등해 1 : 1(라세미)로 생긴다. 기존 답안과 내용이 같으며, 참고 해설은 C의 두 거울상 이성질체를 R/S 표시와 함께 각각 그려 ‘anti 첨가 → 라세미’를 명시한다는 점을 답안 작성 시 참고하면 좋다.

참고: 유기 기출 해설 p.59

알켄·알카인의 반응

2014전공A 기입형 6번8. 알카인[2점]

역-Markovnikov 첨가 → 아세틸라이드 SN2 → 알카인 수화

문제 요지propene —(HBr, HOOH)→ A —(Na⁺ ⁻C≡C–H)→ B —(H₂O, H₂SO₄, HgSO₄)→ C (C₅H₁₀O). A, B, C의 구조.
모범답안A: CH₃CH₂CH₂Br (1-bromopropane)  /  B: CH₃CH₂CH₂C≡CH (1-pentyne)  /  C: CH₃COCH₂CH₂CH₃ (2-pentanone)
핵심 개념 · 공식
  • 과산화물 효과: HBr/ROOR → 라디칼 연쇄 → 역-Markovnikov(1차 브로민화물)
  • 아세틸라이드 음이온 + 1차 할로젠화 알킬 → SN2로 C–C 결합 형성
  • Hg²⁺ 촉매 알카인 수화: Markovnikov → 엔올 → 케토 토토머화 → 메틸 케톤
풀이 과정 · 메커니즘

A: ROOR이 균일 분해 → RO· 가 HBr에서 H를 떼어 Br· 생성 → Br·이 말단 CH₂에 첨가하여 더 안정한 2차 라디칼(CH₃ĊHCH₂Br) 형성 → HBr에서 H 탈취 → 1-bromopropane (+Br· 연쇄 전파).

B: HC≡C⁻ (강한 친핵체)가 1차 탄소를 뒷면 공격(SN2) → 1-pentyne.

C: Hg²⁺가 삼중결합을 활성화하고 H₂O가 더 치환된 탄소(C2)에 첨가(Markovnikov) → 엔올 → 케토형으로 토토머화 → 2-pentanone (C₅H₁₀O 확인).

예상 의문점 Q&A

Q. HOOH가 없으면 A는 무엇이 되나요?

A. 이온성 Markovnikov 첨가로 2-bromopropane이 됩니다. 그러면 다음 단계에서 강염기인 아세틸라이드가 2차 할로젠화물과 E2를 주로 일으켜 propene이 되므로 원하는 B를 얻기 어렵습니다.

Q. 과산화물 효과는 HCl, HI에도 적용되나요?

A. 아닙니다. HBr만 두 전파 단계가 모두 발열입니다. HCl은 H–Cl 결합이 강해 H 탈취가 흡열, HI는 I·의 알켄 첨가가 흡열이라 라디칼 연쇄가 진행되지 않습니다.

Q. C가 pentanal이나 3-pentanone이 아닌 이유는?

A. 말단 알카인의 Hg²⁺ 수화는 Markovnikov로 OH가 내부 탄소(C2)에 붙어 메틸 케톤만 생깁니다. 알데하이드(pentanal)를 원하면 hydroboration(disiamylborane 또는 9-BBN)/산화를 씁니다.

참고 해설 비교 · 보강

정답 일치: A = 1-bromopropane(anti-Markovnikov 첨가), B = 1-pentyne(아세틸라이드의 SN2), C = 2-pentanone(C₅H₁₀O)으로 참고 해설과 같다.

참고 해설의 흐름: HBr/HOOH → 라디칼 첨가로 Br이 말단 탄소에(anti-Markovnikov) → Na⁺⁻C≡C–H가 1차 탄소를 SN2로 공격 → 말단 알카인 → H₂O, H₂SO₄, HgSO₄에서 Markovnikov 수화로 엔올(CH₂=C(OH)CH₂CH₂CH₃)이 먼저 생기고 케토–엔올 토토머화로 2-pentanone이 된다. 기존 답안과 메커니즘·결론이 모두 같다.

알카인·알켄 구조 결정 — 산성 수소, 광학 활성, 수화·오존 분해

2007서술형 9번8. 알카인[4점]

C₆H₁₀ 이성질체 A(열린 사슬, 산성 H)와 B(5각형 고리): 수소화·수화·오존 분해 생성물의 광학 활성

문제 요지분자식 C₆H₁₀인 A와 B는 다음 성질을 갖는 이성질체이다. A: 열린 사슬, acidic hydrogen 있음, 광학 활성(수소화 반응 전) → 수소화 후 광학 비활성, 수화 생성물 C 광학 활성. B: 5각형 고리, acidic hydrogen 없음, 광학 활성 → 수소화 후 광학 비활성, 가오존분해 생성물 D 광학 활성. A —H₃O⁺, HgSO₄→ C, B —1. O₃ 2. Zn/H₃O⁺→ D. A, B, C, D의 구조식을 쓰시오(C와 D는 R-configuration으로). [4점]
모범답안A: (R)-3-methylpent-1-yne, HC≡C–C*H(CH₃)–CH₂CH₃ (말단 알카인 C–H가 산성, C3 카이랄; 수소화 → 3-methylpentane은 C3에 에틸기 2개 → 비카이랄).
C: (R)-3-methylpentan-2-one, CH₃CO–C*H(CH₃)CH₂CH₃ (Markovnikov 수화 → 엔올 → 메틸 케톤, 입체 중심 유지).
B: (R)-3-methylcyclopentene (C3 카이랄, 수소화 → methylcyclopentane 비카이랄; 말단 ≡C–H 없음).
D: (R)-2-methylpentanedial, OHC–C*H(CH₃)–CH₂CH₂–CHO (C=C 절단으로 두 CHO, 입체 중심 유지).
핵심 개념 · 공식
  • 불포화도 = (2×6 + 2 − 10)/2 = 2: 삼중 결합 1개 / 이중 결합 2개 / 고리 + 이중 결합
  • 말단 알카인 ≡C–H: sp 탄소(50% s 성격) → pKₐ ≈ 25, NaNH₂로 탈양성자화(산성 수소)
  • 카이랄 판정: 수소화로 두 치환기가 같아지면 비카이랄 — 3-methylpentane(에틸 2개), methylcyclopentane(대칭면)
  • 알카인 수화(HgSO₄/H₂SO₄): Markovnikov → 엔올 → 케토 토토머화 → 말단 알카인은 메틸 케톤
  • 오존 분해(환원성 처리 Zn/H₃O⁺): 고리 알켄 → 사슬 다이알데하이드
풀이 과정 · 메커니즘

① 불포화도: C₆H₁₀ → (2×6 + 2 − 10)/2 = 2.

② A 결정: 사슬형이므로 불포화도 2는 모두 π 결합에서 온다. HgSO₄/H₃O⁺에서 수화가 일어난다 → 삼중 결합. 산성 수소가 있다 → 말단 삼중 결합(≡C–H, pKa ≈ 25). 수소화 전 광학 활성 → 카이랄, 수소화 후 광학 비활성 → 비카이랄. C₆H₁₀의 말단 알카인 후보: hex-1-yne, 4-methylpent-1-yne, 3,3-dimethylbut-1-yne(모두 비카이랄), 3-methylpent-1-yne(C3 카이랄). 3-methylpent-1-yne의 수소화 생성물 CH₃CH₂CH(CH₃)CH₂CH₃는 C3에 에틸기가 두 개라 비카이랄 ✓.

③ C: Hg²⁺가 삼중 결합을 활성화하고 H₂O가 더 치환된 내부 탄소(C2)에 첨가(Markovnikov) → 엔올 CH₂=C(OH)–CH(CH₃)CH₂CH₃ → 케토–엔올 토토머화 → 3-methylpentan-2-one. C3의 네 치환기(COCH₃, C₂H₅, CH₃, H)가 모두 달라 카이랄 ✓. 반응은 C1·C2에서만 일어나 C3의 배열은 그대로이다. C3 우선순위: COCH₃ > CH₂CH₃ > CH₃ > H — A의 C3 우선순위(C≡CH > CH₂CH₃ > CH₃ > H)와 공간 배치·순서가 같으므로, (R)-C를 주는 A도 (R)이다.

④ B 결정: 5각형 고리(불포화도 1) + π 결합 1개 → cyclopentene 모체에 메틸 1개. 산성 H 없음 ✓. 1-methyl-, 4-methylcyclopentene은 대칭면이 있어 비카이랄 → 3-methylcyclopentene만 카이랄. 수소화(H₂, Pd/C) → methylcyclopentane(대칭면, 비카이랄) ✓.

⑤ D: C1=C2가 오존 분해로 끊어져 C1, C2가 각각 CHO: OHC(C2)–C3H(CH₃)–C4H₂–C5H₂–C1HO = 2-methylpentanedial, 카이랄 ✓. 우선순위: CHO > CH₂CH₂CHO > CH₃ > H — B의 C3(C2(=C) > C4H₂ > CH₃ > H)와 대응 → (R)-B → (R)-D.

예상 의문점 Q&A

Q. C는 산성 수화 조건에서 라셈화되지 않나요?

A. C의 입체 중심은 카보닐 α-탄소이므로 산 촉매 엔올화로 라셈화될 수 있습니다. 문제는 반응 조건에서 입체 중심이 유지된다고 보고(수화는 C1·C2에서만 일어남) C를 광학 활성으로 제시했습니다. 실제로는 온화한 조건·짧은 시간이 필요합니다.

Q. B의 산성 수소가 ‘없다’는 것은 어떻게 쓰이나요?

A. C₆H₁₀의 고리 화합물 중 말단 알카인(예: ethynylcyclobutane 계열)은 산성 H가 있으므로 배제됩니다. 5각형 고리 + 산성 H 없음 → 고리 알켄으로 좁혀집니다.

Q. 우선순위에서 C≡CH가 CH₂CH₃보다 높은 이유는요?

A. 첫 원자는 둘 다 C입니다. 다음 원자 세트를 비교하면 C≡CH는 삼중 결합을 복제 원자로 (C, C, C), CH₂CH₃는 (C, H, H)이므로 C≡CH가 높습니다.

풀이 그림

알카인 — 아세틸라이드 알킬화, 수화, Lindlar 환원, 오존 분해

2006서술형 12번8. 알카인[4점]

acetylene → propyne → A(C₃H₆O) / B(C₅H₈) → C(C₅H₁₀) → acetaldehyde + D(C₃H₆O)

문제 요지Acetylene(C₂H₂) —1. NaNH₂ 2. CH₃I→ propyne —H₂SO₄, HgSO₄, H₂O, HOAc→ A(C₃H₆O); propyne —1. NaNH₂ 2. CH₃CH₂Br→ B(C₅H₈) —H₂, Lindlar catalyst→ C(C₅H₁₀) —1. O₃ 2. Zn, H₃O⁺→ acetaldehyde + D(C₃H₆O). 각 생성물(A–D)의 구조식과 이름을 쓰시오(C는 기하 구조식, cis/trans 또는 Z/E 표시). [4점]
모범답안A: CH₃COCH₃, acetone (propan-2-one) — Markovnikov 수화 → 엔올 → 케토.
B: CH₃C≡CCH₂CH₃, pent-2-yne (2-pentyne) — 프로피나이드의 SN2 에틸화.
C: (Z)-pent-2-ene (cis-2-pentene), CH₃ 와 CH₂CH₃가 같은 쪽 — Lindlar 촉매의 syn 수소 첨가.
D: CH₃CH₂CHO, propanal — C=C 절단(C2 → acetaldehyde, C3 → propanal).
핵심 개념 · 공식
  • 말단 알카인 pKₐ ≈ 25 < NH₃ 38 → NaNH₂로 아세틸라이드 생성, 1° 할로젠화물과 SN2로 C–C 결합 (2°·3°는 E2)
  • 알카인 수화: Hg²⁺ 촉매, Markovnikov → 엔올 → 케토 토토머화
  • Lindlar 촉매(Pd/CaCO₃, Pb(OAc)₂, quinoline): 알카인 → cis-알켄에서 멈춤 / Na, NH₃(l) → trans-알켄
  • 오존 분해 + 환원성 처리: C=C → 두 C=O, 각 탄소의 치환기 그대로
풀이 과정 · 메커니즘
  1. propyne: HC≡CH + NaNH₂ → HC≡C⁻Na⁺(아세틸라이드, ≡C–H pKa ≈ 25 < NH₃ 38) → CH₃I의 탄소를 뒤쪽에서 공격(SN2) → CH₃C≡CH.
  2. A: CH₃C≡CH + H₂O (HgSO₄, H₂SO₄, HOAc) → H가 말단 CH에, OH가 C2에 (Markovnikov) → 엔올 CH₃C(OH)=CH₂ → 케토–엔올 토토머화 → CH₃COCH₃ = acetone. C₃H₆O ✓.
  3. B: CH₃C≡CH + NaNH₂ → CH₃C≡C⁻ → CH₃CH₂Br(1°)에 SN2 → CH₃C≡CCH₂CH₃ = pent-2-yne. C₅H₈ ✓.
  4. C: 피독된 Pd 표면(Lindlar)에서 H 두 개가 삼중 결합의 같은 면에 첨가(syn) → (Z)-pent-2-ene(cis). 알켄은 피독된 촉매 표면에 약하게 흡착해 더 환원되지 않는다. C₅H₁₀ ✓.
  5. D: CH₃CH=CHCH₂CH₃ + O₃ → 몰로조나이드 → 오조나이드 → Zn/H₃O⁺(환원성 처리) → CH₃CHO(acetaldehyde) + CH₃CH₂CHO. D = propanal, C₃H₆O ✓ (A와 구조 이성질체).
구조식이름
ACH₃COCH₃propan-2-one (acetone)
BCH₃C≡CCH₂CH₃pent-2-yne
Ccis-CH₃CH=CHCH₂CH₃(Z)-pent-2-ene
DCH₃CH₂CHOpropanal

참고: 오존 분해 생성물은 C=C의 cis/trans와 무관하므로 D만으로 C의 기하를 알 수는 없다. C의 기하는 Lindlar 환원(syn)에서 결정된다.

참고 해설 대조: A(acetone, 엔올 경유), B(pent-2-yne), C((Z)-pent-2-ene), D(propanal) 모두 일치한다.

예상 의문점 Q&A

Q. B 합성에서 CH₃CH₂Br 대신 2-bromopropane을 쓰면요?

A. 아세틸라이드는 강염기이므로 2° 할로젠화물과는 E2가 우세해 propene이 생기고 알킬화 수율이 매우 낮습니다. 알킬화는 메틸·1° 할로젠화물에 한정됩니다.

Q. A의 수화에서 aldehyde(propanal)는 왜 안 생기나요?

A. Hg²⁺ 촉매 수화는 Markovnikov 방향이라 말단 알카인에서는 메틸 케톤이 생깁니다. 알데하이드를 원하면 수소붕소화(disiamylborane 또는 9-BBN) → H₂O₂/OH⁻를 사용합니다.

Q. E-2-pentene을 만들려면요?

A. B를 Na(또는 Li)/NH₃(l)로 용해 금속 환원하면 라디칼 음이온 → 비닐 라디칼 → 비닐 음이온이 더 안정한 trans 배치를 취해 (E)-pent-2-ene이 됩니다.
