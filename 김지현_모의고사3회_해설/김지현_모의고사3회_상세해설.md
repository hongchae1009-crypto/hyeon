# 전공 A

## A형 1번 · 내부 압력과 진공으로의 단열 팽창 {#a1}

<img class="q" src="img/A01.png" alt="A형 1번 문항">

<div class="ans" markdown="1">

**정답** $\pi_T = \dfrac{naT^2}{V}$, $T_2 = 300\times3^{-a/b}\ \mathrm{K} = 300\,e^{-(a/b)\ln3}\ \mathrm{K}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $\pi_T = T(\partial p/\partial T)_V - p$
- $dU = C_VdT + \pi_TdV$
- 진공으로의 단열 팽창: $q = w = 0$ → $\Delta U = 0$ (Joule 팽창)

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 내부 압력과 Joule 팽창은 열역학 관계식 문항의 단골 변형입니다(4회 B형 10번과 같은 계열).

</div>

**내부 압력.** $\pi_T = T\left(\dfrac{\partial p}{\partial T}\right)_V - p$이고, $p = \dfrac{nRT + naT^2}{V}$이므로

$$\pi_T = T\cdot\frac{nR + 2naT}{V} - \frac{nRT + naT^2}{V} = \frac{naT^2}{V}$$

**최종 온도.** 진공으로의 팽창은 $w = 0$, 단열이라 $q = 0$ → $dU = 0$:

$$C_VdT + \pi_TdV = nbT\,dT + \frac{naT^2}{V}dV = 0 \;\Rightarrow\; b\frac{dT}{T} = -a\frac{dV}{V}$$

$$b\ln\frac{T_2}{300} = -a\ln3 \;\Rightarrow\; T_2 = 300\times3^{-a/b}\ \mathrm{K}$$

**채점 포인트·함정**

- 이상기체였다면 $\pi_T = 0$이라 온도가 변하지 않습니다. 이 기체는 $a > 0$이면 냉각됩니다.

## A형 2번 · CH₄의 광전자 스펙트럼 {#a2}

<img class="q" src="img/A02.png" alt="A형 2번 문항">

<div class="ans" markdown="1">

**정답** (A) **T₂** = (c) **1t₂**, (B) **A₁** = (d) **1a₁**. (c)는 C의 2p 하나와 같은 부호로 겹치는 H 1s 4개 조합(세 개 중 하나: 예 C 2pz + 위쪽 H 두 개 +, 아래쪽 두 개 −)

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- Td H 1s SALC: $A_1 + T_2$
- 쿠프만스 정리: IE = −ε(MO)
- PES 띠 세기 ∝ 그 MO의 전자 수

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 광전자 스펙트럼과 MO 대응은 무기 서술형에서 자주 나옵니다. H₂O·NH₃·CO로 바뀌어 나올 수 있습니다.

</div>

**H 1s SALC.** Td에서 Γ(4H) = 4, 1, 0, 0, 2 → **A₁ + T₂**. C 2s는 A₁, 2p는 T₂(x, y, z)와 맞습니다.

**MO 순서.** 결합성 1a₁(d, 가장 낮음) < 1t₂(c, 삼중 축퇴) < 비결합 없음 < 반결합성 2a₁(b), 2t₂(a). 전자 8개가 1a₁², 1t₂⁶을 채웁니다.

**PES.** 이온화 에너지가 작은 (A, ~14 eV)가 **1t₂**(전자 6개라 세기가 큼, Jahn–Teller로 넓게 갈라짐), 큰 (B, ~23 eV)가 **1a₁**입니다(쿠프만스 정리: IE = −ε).

**채점 포인트·함정**

- 띠 세기가 대략 3 : 1인 것(전자 6 : 2)도 근거로 쓸 수 있습니다.

## A형 8번 · HCl의 진동-회전 스펙트럼 {#a8}

<img class="q" src="img/A08.png" alt="A형 8번 문항">

<div class="ans" markdown="1">

**정답** $\Delta = 4\tilde B$, $\varepsilon_1 - \varepsilon_0 = 2hc\tilde B$, $\dfrac{N_1}{N_0} = 3e^{-2hc\tilde B/kT}$. J = 1이 J = 0보다 에너지는 높지만 **3중 축퇴**라 개체수가 더 많다.

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $R(J) = \tilde\nu + 2\tilde B(J+1)$, $P(J) = \tilde\nu - 2\tilde BJ$
- $E_J = hc\tilde BJ(J+1)$, 축퇴도 $2J+1$
- $N_J/N_0 = (2J+1)e^{-E_J/kT}$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 진동-회전 스펙트럼 해석은 물리화학 분광 단골입니다.

</div>

**가지의 위치.** $R(J) = \tilde\nu + 2\tilde B(J + 1)$, $P(J) = \tilde\nu - 2\tilde BJ$. 가운데 두 봉우리는 R(0)과 P(1):

$$\Delta = [\tilde\nu + 2\tilde B] - [\tilde\nu - 2\tilde B] = 4\tilde B$$

(Q 가지(ΔJ = 0)는 없어서 가운데가 비어 있습니다.)

**개체수.** $E_J = hc\tilde BJ(J+1)$, 축퇴도 $2J + 1$:

$$\frac{N_1}{N_0} = \frac{3}{1}e^{-2hc\tilde B/kT}$$

HCl($\tilde B \approx 10.6\ \mathrm{cm^{-1}}$), 25 °C($kT/hc \approx 207\ \mathrm{cm^{-1}}$): $3e^{-0.102} \approx 2.7$ → J = 1이 더 많음.

## B형 6번 · 엔트로피 변화율과 압축·J-T 냉각 {#b6}

<img class="q" src="img/B06.png" alt="B형 6번 문항">

<div class="ans" markdown="1">

**정답** $a = -\alpha V$, $b = \dfrac{\alpha}{\kappa_T}$, 에탄올 $\Delta p = -\dfrac{\ln0.9}{\kappa_T}$, CO₂ **5.0 atm** 떨어뜨림

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 맥스웰: $(\partial S/\partial p)_T = -(\partial V/\partial T)_p$, $(\partial S/\partial V)_T = (\partial p/\partial T)_V$
- $(\partial p/\partial T)_V = \alpha/\kappa_T$
- $\Delta T = \mu_{JT}\Delta p$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 맥스웰 관계식 응용은 물리화학 기입형에 가끔 나옵니다.

</div>

**맥스웰 관계식.** $\left(\dfrac{\partial S}{\partial p}\right)_T = -\left(\dfrac{\partial V}{\partial T}\right)_p = -\alpha V$, $\left(\dfrac{\partial S}{\partial V}\right)_T = \left(\dfrac{\partial p}{\partial T}\right)_V = \dfrac{\alpha}{\kappa_T}$ (순환 관계 $(\partial p/\partial T)_V = -(\partial V/\partial T)_p/(\partial V/\partial p)_T$).

**에탄올 압축.** $dV/V = -\kappa_Tdp$ → $\ln0.900 = -\kappa_T\Delta p$ → $\Delta p = -\dfrac{\ln0.900}{\kappa_T}$ (≈ 0.105/κT).

**J-T 냉각.** $\Delta T \approx \mu_{JT}\Delta p$ → $\Delta p = -5.0/1.0 = -5.0$ atm → 압력을 5.0 atm 낮춥니다.

**채점 포인트·함정**

- 기체 A의 $(\partial U/\partial V)_T = 0$, $(\partial H/\partial p)_T = 0$ 조건은 a, b 식에 직접 필요하지 않습니다(완전 기체라면 a = −nR/p, b = nR/V로 확인 가능).

## B형 7번 · 시험 파동함수의 에너지 {#b7}

<img class="q" src="img/B07.png" alt="B형 7번 문항">

<div class="ans" markdown="1">

**정답** ψ(0) = ψ(L) = 0이므로 **경계조건 만족**. 두 함수 모두 $\langle E\rangle = \dfrac{5h^2}{4\pi^2mL^2}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 경계조건 ψ(0) = ψ(L) = 0
- $\langle E\rangle = \dfrac{\langle\psi|\hat H|\psi\rangle}{\langle\psi|\psi\rangle}$
- 변분 원리: 시험 에너지 ≥ 참 바닥 에너지

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 변분법은 양자 영역에서 가끔 나오는 고급 소재입니다.

</div>

**정규화되지 않은 함수(2).** $\hat H = -\dfrac{\hbar^2}{2m}\dfrac{d^2}{dx^2}$, $\psi'' = -2$:

$$\langle E\rangle = \frac{\int\psi\hat H\psi\,dx}{\int\psi^2dx} = \frac{\frac{\hbar^2}{m}\int_0^Lx(L-x)dx}{\int_0^Lx^2(L-x)^2dx} = \frac{\hbar^2L^3/6m}{L^5/30} = \frac{5\hbar^2}{mL^2} = \frac{5h^2}{4\pi^2mL^2}$$

정규화된 함수(1)는 분모가 1이고 같은 값입니다(정규화 상수는 에너지에 영향 없음).

**변분 원리 확인.** 정확한 바닥 상태 $\dfrac{h^2}{8mL^2}$와 비교하면 $\dfrac{5/4\pi^2}{1/8} = \dfrac{10}{\pi^2} = 1.013$ → 시험 함수 에너지가 1.3% 높음(항상 ≥ 참값).

**채점 포인트·함정**

- 정규화 안 된 함수는 반드시 **분모 ⟨ψ|ψ⟩로 나눕니다**.

## B형 11번 · CO₂를 흡수한 NaOH와 지시약 {#b11}

<div class="key" markdown="1">

- 페놀프탈레인: CO₃²⁻ → HCO₃⁻ / BCG: → H₂CO₃
- 표준화와 적정에 같은 지시약 → 탄산 오차 상쇄

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 탄산 오차는 산염기 적정 실험 문항의 고전적 소재입니다.

**탄산 오차.** CO₂ 흡수: 2OH⁻ + CO₂ → CO₃²⁻ + H₂O.

- 브로모크레졸그린(pH ≈ 4–5): CO₃²⁻ → H₂CO₃(H⁺ 2개) → 원래 염기량 전부

**(2)** HCl = 0.0900 × 11.0 / 10.0 = **0.099 M**.

**(4)** 표준화와 적정을 **같은 지시약(페놀프탈레인)**으로 했으므로 탄산 오차가 서로 상쇄되어 0.099 M이 참값입니다. 표준화와 적정의 지시약이 다르면 오차가 남습니다.
