# 해설 원고 작성 지침 (회차별 expl_N.py)

대상: /home/user/hyeon/모의고사/mockN.py 의 ITEMS 6문항(전공A 5·6·7, 전공B 3·4·5). 문항 데이터(stem, blocks, how, ans, score, note)를 꼼꼼히 읽고, 각 문항의 **상세 해설**을 작성한다. mockN.py 자체는 절대 수정하지 않는다.

## 출력 파일
/home/user/hyeon/모의고사/해설/expl_N.py (UTF-8). 형식:
```python
# -*- coding: utf-8 -*-
EXPL = {
  ("A", 5): [
     ("핵심 개념", "<p>...</p>"),
     ("작성 방법별 해설", "<p><b>작성 1</b> ...</p><p><b>작성 2</b> ...</p>"),
     ("채점 포인트·감점 사례", "<p>...</p>"),
     ("교육과정·기출 연계", "<p>...</p>"),
  ],
  ...6문항 모두...
}
```
- 값은 HTML 조각(<p>, <b>, <u>, <sub>, <sup>, <br>, 간단한 <table><tr><th><td> 만). 클래스·스타일 쓰지 말 것. 파이썬 문법 오류 없게(삼중따옴표 r''' ''' 권장, 내부에 ''' 금지).
- 섹션 4개는 위 제목·순서 그대로. 필요하면 5번째 섹션 ("더 알아두기", ...)을 추가해도 된다(관련 이론 비교표, 예상 변형 발문 등).

## 섹션별 내용
1. **핵심 개념**: 문항이 묻는 교육론 이론/탐구 개념/화학 개념을 수험생이 답안을 쓸 수 있을 정도로 정리. 모형이면 단계 전체와 각 단계 특징, 유형 구분이면 유형별 비교(표 권장), 학자 관점이면 핵심 용어 정의. 4~8문장 또는 표.
2. **작성 방법별 해설**: 작성 방법 bullet마다 "작성 1, 작성 2, (작성 3)"으로 나눠, <자료>의 어느 부분((가), 밑줄 ㉠, 대화 등)이 근거인지 짚으며 정답에 이르는 사고 과정을 구체적으로 설명. 계산 문항은 단계별 식과 단위, 유효숫자까지. 오차 방향은 '무엇이 커지고 → 그래서 결과가 어떻게 되는지' 인과 사슬로. 각 작성 끝에 **모범 답안 문장**을 한 번 더 제시("→ 모범 답안: ...").
3. **채점 포인트·감점 사례**: 요소별 필수 키워드, 인정 가능한 유사 표현, 흔한 오답/감점 사례(예: 용어만 쓰고 근거 없음, 비슷한 다른 개념과 혼동) 2~4개.
4. **교육과정·기출 연계**: 문항에 인용된 2022 개정 교육과정 문장의 위치(과목, 영역, 성취기준 해설/적용 시 고려 사항/교수·학습/평가)와 그것이 이 문항에서 어떤 역할인지. 관련 기출은 문항 note와 /home/user/hyeon/변형문제_작업/기출분석_원자료.md 에 있는 것만 인용(연도·과목·번호를 지어내지 말 것). 2027 출제 포인트 1~2줄.

## 규칙
- 한국어. 수험서 해설 문체("~이다", "~해야 한다").
- 교육과정 문장을 인용할 때는 /home/user/hyeon/변형문제_작업/교육과정/*.md 원문 그대로만. 원문에 없는 문장을 교육과정이라고 쓰지 말 것.
- 교사용 지도서 내용은 넣지 않는다. 오개념, 지도상 유의점, 탐구 활동 시 유의점 수준의 일반적 설명은 가능.
- 모범 답안(ans)과 모순되는 내용 금지. ans에 오류·모호함을 발견하면 해설에서 바꾸지 말고, 작업 끝 보고에 "확인 필요"로 적을 것.
- 화학 사실·수치는 정확하게(계산은 python으로 검산).
- 분량: 문항당 대략 한글 1,000~1,600자(표 제외). 너무 길게 늘이지 말 것.
