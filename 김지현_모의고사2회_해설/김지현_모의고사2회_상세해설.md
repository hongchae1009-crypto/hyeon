# 전공 A

## A형 1번 · 이합체화 반응의 완화 시간 {#a1}

<img class="q" src="img/A01.png" alt="A형 1번 문항">

<div class="ans" markdown="1">

**정답** (1) $\tau = \dfrac{1}{4k_a[A]_{eq} + k_a'}$  (2) $\dfrac{1}{\tau^2} = 8k_ak_a'[A]_{tot} + (k_a')^2$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 완화법: 평형에서 작은 변위 $x$, $dx/dt = -x/\tau$
- $2A \rightleftharpoons A_2$: $\tau^{-1} = 4k_a[A]_{eq} + k_a'$
- $A \rightleftharpoons B$: $\tau^{-1} = k_1 + k_{-1}$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 완화법은 속도론에서 가끔 나오는 고급 소재입니다. 단순 가역 반응 $\tau^{-1} = k_1 + k_{-1}$부터 확실히 하세요.

</div>

**완화법.** 평형에서 조금 벗어난 양 $x$로 $[A] = [A]_{eq} + x$, $[A_2] = [A_2]_{eq} - x/2$를 놓습니다. A의 속도식

$$\frac{d[A]}{dt} = -2k_a[A]^2 + 2k_a'[A_2]$$

에 대입하고 $x^2$ 항을 버리면(평형 조건으로 상수항 소거)

$$\frac{dx}{dt} = -(4k_a[A]_{eq} + k_a')x \;\Rightarrow\; \frac1\tau = 4k_a[A]_{eq} + k_a'$$

**[A]tot로 바꾸기.** 양변을 제곱하면 $\tau^{-2} = 16k_a^2[A]_{eq}^2 + 8k_ak_a'[A]_{eq} + k_a'^2$. 평형 $k_a[A]_{eq}^2 = k_a'[A_2]_{eq}$와 $[A]_{tot} = [A]_{eq} + 2[A_2]_{eq}$에서 $16k_a^2[A]_{eq}^2 = 8k_ak_a'(2[A_2]_{eq})$이므로

$$\frac{1}{\tau^2} = 8k_ak_a'([A]_{eq} + 2[A_2]_{eq}) + k_a'^2 = 8k_ak_a'[A]_{tot} + (k_a')^2$$

**채점 포인트·함정**

- 이 식은 $\tau^{-2}$를 $[A]_{tot}$에 대해 그리면 직선이 되어, 기울기와 절편으로 $k_a$, $k_a'$을 함께 구할 수 있다는 것이 핵심입니다.
- 계수 2(2A)를 빠뜨리면 $4k_a$ 대신 $2k_a$가 나옵니다.

## A형 2번 · 수은의 전위차 EDTA 적정 {#a2}

<img class="q" src="img/A02.png" alt="A형 2번 문항">

<div class="ans" markdown="1">

**정답** $E_{cell} = 0.192$ V

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 조건 형성상수 $K_f' = \alpha_{Y^{4-}}K_f$
- EDTA 과량 영역: $[M] = \dfrac{[MY]}{K_f'[EDTA]}$
- 네른스트 $E = E^\circ - \dfrac{0.0600}{n}\log\dfrac{1}{[M^{n+}]}$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — EDTA 적정과 전기화학을 엮는 계산은 분석화학에서 자주 나옵니다(4회 B형 2번과 같은 계열).

</div>

**양적 관계.** EDTA 5.00 mmol, Hg²⁺ 1.00 mmol → HgY²⁻ 1.00 mmol, 남은 EDTA 4.00 mmol, 전체 60.0 mL.

**[Hg²⁺].** 조건 형성상수 $K_f' = \alpha_{Y^{4-}}K_f = 0.25 \times 10^{22}$:

$$[\mathrm{Hg^{2+}}] = \frac{[\mathrm{HgY^{2-}}]}{K_f'[\mathrm{EDTA}]} = \frac{1.00/60.0}{0.25\times10^{22}\times(4.00/60.0)} = 1.0\times10^{-22}\ \mathrm{M}$$

**전위.** 기준 전극이 표준 수소 전극(0 V)이므로

$$E_{cell} = E_{Hg} = 0.852 - \frac{0.0600}{2}\log\frac{1}{10^{-22}} = 0.852 - 0.660 = 0.192\ \mathrm{V}$$

**채점 포인트·함정**

- 부피는 약분되어 사라지지만(1 : 4 비), 비를 쓰기 전에 남은 EDTA 양을 정확히 구해야 합니다.
- $\alpha_{Y^{4-}}$를 곱해 조건 형성상수로 바꾸는 단계를 빼먹기 쉽습니다.

## A형 8번 · 상자 속 입자의 불확정성 {#a8}

<img class="q" src="img/A08.png" alt="A형 8번 문항">

<div class="ans" markdown="1">

**정답**

- $\langle x\rangle = \dfrac L2$, $\langle x^2\rangle = L^2\left(\dfrac13 - \dfrac{1}{2n^2\pi^2}\right)$, $\Delta x = L\left(\dfrac1{12} - \dfrac{1}{2n^2\pi^2}\right)^{1/2}$
- $\langle p\rangle = 0$, $\langle p^2\rangle = \dfrac{n^2h^2}{4L^2}$, $\Delta p = \dfrac{nh}{2L}$
- $\Delta x\Delta p = \dfrac{nh}{2}\left(\dfrac1{12} - \dfrac{1}{2n^2\pi^2}\right)^{1/2} > \dfrac\hbar2$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $\psi_n = \sqrt{2/L}\sin(n\pi x/L)$, $E_n = \dfrac{n^2h^2}{8mL^2}$
- $\Delta A = \sqrt{\langle A^2\rangle - \langle A\rangle^2}$
- $\langle p^2\rangle = 2mE$, 불확정성 $\Delta x\Delta p \ge \hbar/2$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 상자 속 입자 기대치는 양자 영역의 기본형입니다. 적분 공식을 주는 형태로 출제됩니다.

</div>

**⟨x²⟩.** 주어진 적분 공식에 $b = n\pi/L$, 구간 0~L을 넣으면 sin 항은 0, cos 항은 $\cos(2n\pi) = 1$:

$$\langle x^2\rangle = \frac2L\left[\frac{L^3}{6} - \frac{L}{4b^2}\right] = L^2\left(\frac13 - \frac{1}{2n^2\pi^2}\right)$$

$\Delta x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}$에서 $\frac13 - \frac14 = \frac1{12}$.

**⟨p⟩, ⟨p²⟩.** $\hat p = -i\hbar\frac{d}{dx}$: sin × cos 적분이 0이므로 $\langle p\rangle = 0$. $\hat p^2\psi = \hbar^2b^2\psi$이므로 $\langle p^2\rangle = \dfrac{n^2\pi^2\hbar^2}{L^2} = \dfrac{n^2h^2}{4L^2}$ (= 2mE).

**불확정성 확인.** n = 1: $\frac{h}{2}\sqrt{0.0833 - 0.0507} = 0.0903h = 0.567\hbar > 0.5\hbar$ ✓.

**채점 포인트·함정**

- $\langle x\rangle$와 $\langle p\rangle$는 **모든 n**에 대해 같다고 써야 합니다(대칭).

## B형 6번 · Clapeyron 식과 2차 상전이 {#b6}

<img class="q" src="img/B06.png" alt="B형 6번 문항">

<div class="ans" markdown="1">

**정답**

- $d\left(\dfrac{\Delta H}{T}\right) = \dfrac{\Delta C_p}{T}dT = \Delta C_p\,d\ln T$
- $\dfrac{dp}{dT} = \dfrac{\alpha_2 - \alpha_1}{\kappa_{T,2} - \kappa_{T,1}}$
- $\dfrac{dp}{dT} = \dfrac{C_{p,m2} - C_{p,m1}}{TV_m(\alpha_2 - \alpha_1)}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- Clapeyron: $\dfrac{dp}{dT} = \dfrac{\Delta H}{T\Delta V}$
- 2차 상전이(Ehrenfest): $\dfrac{dp}{dT} = \dfrac{\Delta\alpha}{\Delta\kappa_T} = \dfrac{\Delta C_{p,m}}{TV_m\Delta\alpha}$
- $dV = V(\alpha dT - \kappa_T dp)$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 상평형 열역학은 Clapeyron 수준에서 자주, Ehrenfest 식은 드물게 나옵니다.

</div>

**(1)** 상 경계를 따라 $d\Delta H = \Delta C_p dT + \Delta V dp$이고, Clapeyron 식 $\Delta V dp = \dfrac{\Delta H}{T}dT$를 넣으면

$$d\left(\frac{\Delta H}{T}\right) = \frac{d\Delta H}{T} - \frac{\Delta H}{T^2}dT = \frac{\Delta C_p}{T}dT$$

**(2) 2차 상전이 (Ehrenfest).** $\Delta V = 0$, $\Delta H = 0$이라 Clapeyron 식이 0/0이 됩니다. 대신 두 상의 몰부피 변화가 경계를 따라 같다는 조건 $dV_1 = dV_2$:

$$V(\alpha_1 dT - \kappa_1 dp) = V(\alpha_2 dT - \kappa_2 dp) \;\Rightarrow\; \frac{dp}{dT} = \frac{\alpha_2 - \alpha_1}{\kappa_{T,2} - \kappa_{T,1}}$$

**(3)** 엔트로피 조건 $dS_1 = dS_2$, $dS = \dfrac{C_p}{T}dT - \alpha V dp$:

$$\frac{dp}{dT} = \frac{C_{p,m2} - C_{p,m1}}{TV_m(\alpha_2 - \alpha_1)}$$

**채점 포인트·함정**

- 공식 답안 분모의 $\kappa_{T,2} - \kappa_{T,2}$는 오타입니다(검토 메모 1).

## B형 7번 · Hückel 근사: TMM과 알릴 라디칼 {#b7}

<img class="q" src="img/B07.png" alt="B형 7번 문항">

<div class="ans" markdown="1">

**정답** TMM: 전체 $4\alpha + 2\sqrt3\beta$, 비편재화 $(2\sqrt3 - 2)\beta$ / 알릴 라디칼: 전체 $3\alpha + 2\sqrt2\beta$, 비편재화 $(2\sqrt2 - 2)\beta$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- Hückel: $E = \alpha + x\beta$, 영년식 풀기
- 전체 π 에너지 = Σ(전자 수 × 준위 에너지)
- 비편재화 에너지 = 전체 − 국소화 구조 에너지

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — Hückel 계산은 물리화학·유기 경계 소재로 자주 나옵니다.

</div>

**TMM 영년식 풀기.** $x = (\alpha - E)/\beta$로 놓으면 $x^2(x^2 - 3) = 0$ → $E = \alpha \pm \sqrt3\beta$, $\alpha$(이중 축퇴).

π 전자 4개: $2(\alpha + \sqrt3\beta) + 1\cdot\alpha + 1\cdot\alpha = 4\alpha + 2\sqrt3\beta$ (축퇴된 비결합 오비탈에 홀전자 2개 — 이중 라디칼).

국소화 구조(C=C 1개 + 홀전자 2개) $= 2(\alpha + \beta) + 2\alpha = 4\alpha + 2\beta$ → 비편재화 에너지 $(2\sqrt3 - 2)\beta \approx 1.46\beta$.

**알릴.** $x(x^2 - 2) = 0$ → $E = \alpha \pm \sqrt2\beta$, $\alpha$. 전자 3개: $2(\alpha + \sqrt2\beta) + \alpha = 3\alpha + 2\sqrt2\beta$. 국소화 $3\alpha + 2\beta$ → 비편재화 $(2\sqrt2 - 2)\beta \approx 0.83\beta$.

**채점 포인트·함정**

- β < 0이므로 $(2\sqrt3 - 2)\beta$는 **안정화**(음수 에너지)를 뜻합니다.

**[Co(NH₃)₆]³⁺.** Co³⁺ d⁶ 저스핀(도표 오른쪽, Δ/B > 20). 스핀 허용 전이는 ¹A₁g → ¹T₁g(낮은 에너지, 긴 파장), ¹T₂g. 가장 아래 들뜬 단일항이 ¹T₁g입니다.

**F⁻ 착물 (약한 장, 고스핀).**

- [FeF₆]³⁻: Fe³⁺ d⁵ → **⁶A₁g**. 도표에 스핀 다중도 6인 들뜬 상태가 **없어** 모든 d–d 전이가 스핀 금지 → 흡수가 매우 약해 **무색**.
- [CoF₆]³⁻: Co³⁺ d⁶ 고스핀 → **⁵T₂g**. 같은 다중도의 들뜬 상태 **⁵Eg**가 있어 스핀 허용 전이 1개 → 가시광선 흡수 → **색**.

**채점 포인트·함정**

- F⁻는 Co³⁺에도 약한 장이라 **고스핀**입니다(NH₃와 다름).

## B형 10번 · Sertraline 중간체 합성 {#b10}

<img class="q" src="img/B10.png" alt="B형 10번 문항">

<div class="ans" markdown="1">

**정답** B **γ-락톤** 5-(3,4-dichlorophenyl)dihydrofuran-2-one, C **4-(3,4-dichlorophenyl)-4-phenylbutanoic acid**, D **4-(3,4-dichlorophenyl)-3,4-dihydronaphthalen-1(2H)-one**

<img class="s" src="img/s_B10.svg" alt="A~D 구조">

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- NaBH₄: 케톤 선택적 환원
- Friedel–Crafts 알킬화: 안정한 탄소양이온 경유
- 분자 내 아실화 → 6원 고리 케톤(테트랄론)

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 의약품 합성 경로 해석은 유기 고난도 서술형으로 출제됩니다.

</div>

**A → B.** NaBH₄가 케톤만 환원(카복실산은 그대로) → γ-하이드록시산 → HCl로 분자 내 에스터화 → 5원 고리 락톤 (C₁₀H₈O₂Cl₂ ✓).

**B → C (주생성물 이유).** AlCl₃가 락톤의 고리 산소에 배위하면 C–O 결합이 끊어지면서 **벤질 탄소양이온(구조 [1])**이 생깁니다. 이 양이온은 아릴 고리와 공명해 안정하므로 아실륨형 양이온(구조 [2])보다 우세하고, 벤젠이 이 탄소를 공격하는 **Friedel–Crafts 알킬화**로 C가 생깁니다(C₁₆H₁₄O₂Cl₂ ✓).

**C → D.** SOCl₂로 산 염화물 → AlCl₃로 **분자 내 Friedel–Crafts 아실화**. 전자가 더 풍부한 **비치환 페닐 고리**가 공격받아 6원 고리 테트랄론 D(C₁₆H₁₂OCl₂ ✓). 이후 CH₃NH₂(이민) → H₂/Pd-C(환원) → sertraline.

**채점 포인트·함정**

- 아실화가 다이클로로페닐 쪽이 아니라 **페닐 쪽**에서 일어나는 이유(Cl은 고리를 비활성화)를 쓰면 좋습니다.

## B형 11번 · 모세관 전기이동과 전기삼투 {#b11}

<img class="q" src="img/B11.png" alt="B형 11번 문항">

<div class="ans" markdown="1">

**정답** 이동 시간 **B⁻ > C > A⁺**. pH 10에서 실리카 > 아미노프로필, pH 2.5에서 실리카 흐름 ≈ 0, 아미노프로필은 반대 방향. 검출 시간 **250 s**

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $u_{net} = u_{ep} + u_{eo}$
- 실리카 벽 Si–O⁻ → 음극 쪽 EOF, pH↓ → EOF↓
- 이동 순서: 양이온 → 중성 → 음이온

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 모세관 전기이동은 분석화학 기기분석에서 꾸준히 나옵니다.

</div>

**이동 순서.** 전기삼투 흐름(EOF)이 음극(검출기) 쪽으로 모든 성분을 운반합니다. 양이온은 EOF + 전기이동이 같은 방향 → 가장 빠름, 중성 C는 EOF 속도, 음이온은 전기이동이 반대 → 가장 느림. 걸리는 시간: **B⁻ > C > A⁺**.

**벽 전하와 EOF.**

| 모세관 | pH 10 | pH 2.5 |
|---|---|---|
| 노출된 실리카 | Si–O⁻ 많음 → 강한 EOF (+3.1) | Si–OH 거의 중성 → EOF ≈ 0 (+0.2) |
| 아미노프로필 | Si–O⁻ 일부가 아미노기로 대체·일부 양성자화 → 약해짐 (+1.8) | –NH₃⁺로 벽이 **양전하** → EOF **반대 방향** (−1.3) |

**검출 시간.**

$$u_{net} = u_{ep} + u_{eo} = 0.80 + 0.80 = 1.60\ \mathrm{mm/s} = 0.160\ \mathrm{cm/s}, \quad t = \frac{40.0}{0.160} = 250\ \mathrm{s}$$

**채점 포인트·함정**

- 음수 EOF는 "작아짐"이 아니라 **방향 역전**입니다(검토 메모 2).
