# 중등 화학 임용 — 유기화학 단원별 기출 모범답안

`유기화학_단원별_모범답안/` 폴더 (1~21단원, 134문항)
- `유기화학_NN_단원명.html / .pdf` : 단원별 파일
- `유기화학_단원별_모범답안_합본.html` : 전체 합본 (왼쪽 메뉴에서 **단원별 / 연도별 보기** 전환, 단원 필터, 검색)
- `…합본(단원순).pdf`, `…합본(연도순).pdf` : 인쇄용 (단원·연도마다 새 페이지, 제목은 첫 문항과 같은 페이지)

각 문항: 문제 요지 → 모범답안 → 핵심 개념·공식 → 풀이 과정·메커니즘(계산 포함) → 구조식 그림(SVG) → 예상 의문점 Q&A

## 다시 만들기
```
pip install playwright pymupdf
python3 tools/build.py <기존 모범답안.html> 유기화학_단원별_모범답안 content_17_20 [다른 content 모듈 …]
```
(`tools/` 안에서 실행; `chemsvg.py`는 구조식 SVG 그리기 도구, `figs_*.py`는 문항별 그림, `content_*.py`는 문항 본문)
