# 과교론 출제 경향 & 2027 출제 예상 주제

근거: 화교론 2014–2026(78문항), 물리·생물·지구과학 2024–2026(물리 2025 B5 제외 59문항) 분석 → `기출분석_원자료.md`

## 1. 형식 (2021~ 고정)
- 과목당 6문항(전공A 5·6·7번, 전공B 3·4·5번), 모두 4점 서술형
- <자료>(예비 교사–지도 교사 대화 / 수업 지도안 / 활동지 / 보고서 / 평가표 / 과학사) + 빈칸 ㉠~㉤ + <작성 방법> 2~3개
- 한 문항 = **교육론 이론 1~2개 + 교과 내용 오류 수정 또는 교육과정 적용**의 결합형
- 2025~ "2022 개정 과학과 교육과정(교육부 고시 제2022-33호)" 명시

## 4. 변형문제 제작 원칙
1. 원 기출의 **<자료> 구조·작성방법 형식**을 유지하고, 소재를 22개정 교과서 탐구 활동으로 교체
2. 교과서 탐구의 **유의점(안전·변인·측정)**, 관련 **오개념**, **성취기준 해설(다루지 않는 범위)**을 빈칸·오류 찾기 포인트로 삽입
3. 각 문항: `[원기출: 20XX 과목 A/B n번 변형]`, `중요도/출제가능성 ★★★★☆`, 예시 답안, 출제 포인트
