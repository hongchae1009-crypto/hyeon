## A형 1번 · 3준위 계의 볼츠만 분포 {#a1}

<img class="q" src="img/A01.png" alt="A형 1번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★☆☆☆) 분자가 III에 있을 확률 **1/5**. T → ∞: I **1/5**, II **2/5**, III **2/5**

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $N_i \propto g_i\,e^{-\varepsilon_i/kT}$, 확률 $p_i = \dfrac{g_ie^{-\varepsilon_i/kT}}{q}$
- 분배함수 $q = \sum g_ie^{-\varepsilon_i/kT}$
- $T\to\infty$: $p_i \to g_i/\sum g_i$, $T\to0$: 바닥 준위만

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 통계열역학(볼츠만 분포·분배함수)은 물리화학 기입형에 주기적으로 나옵니다. 축퇴도가 있는 준위 계산이 기본형입니다.

</div>

**볼츠만 분포.** 준위 $i$의 분자 수는 $N_i \propto g_i e^{-\varepsilon_i/kT}$입니다.

**(1) N_I : N_II = 1 : 1인 온도.**

$$\frac{N_{II}}{N_I} = \frac{2}{1}e^{-\varepsilon/kT} = 1 \;\Rightarrow\; e^{-\varepsilon/kT} = \frac12$$

$$\frac{N_{III}}{N_I} = \frac{2}{1}e^{-2\varepsilon/kT} = 2\left(\frac12\right)^2 = \frac12$$

N_I : N_II : N_III = 1 : 1 : ½ = 2 : 2 : 1 → III에 있을 확률 $= \dfrac{1}{5}$.

**(2) T → ∞.** $e^{-\varepsilon/kT} \to 1$이므로 분포는 축퇴도만으로 정해집니다: 1 : 2 : 2 → $\dfrac15, \dfrac25, \dfrac25$.

**채점 포인트·함정**

- 축퇴도를 빼먹고 $e^{-\varepsilon/kT} = 1$로 놓으면 (1)이 틀립니다.
- 무한 온도에서 확률이 "모두 1/3"이 아니라 **축퇴도에 비례**한다는 점이 핵심입니다.

## A형 4번 · 평행 반응의 속도론 {#a4}

<img class="q" src="img/A04.png" alt="A형 4번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★☆☆☆) $t_1 = 1$ s, 2t₁에서 $\dfrac{[B]}{[C]} = \dfrac32$, $[C] = \dfrac{3\alpha}{7}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 평행 1차 반응: $[A] = [A]_0e^{-(k_1+k_2)t}$, $t_{1/2} = \dfrac{\ln2}{k_1+k_2}$
- 생성물 비 = 속도 상수 비(계수 반영): $[B]/[C] = 2k_b/k_c$
- C로 가는 분율 $= k_c/(k_b+k_c)$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 속도론은 2024 기출처럼 메커니즘·적분 속도식으로 자주 나옵니다. 평행·연속 반응은 2027에도 유력합니다.

</div>

**반감기.** A의 소멸 속도는 두 경로의 합: $-\dfrac{d[A]}{dt} = (k_b + k_c)[A]$ → 1차 반응, $k = 0.7\ \mathrm{s^{-1}}$.

$$t_{1/2} = \frac{\ln 2}{k_b + k_c} = \frac{0.7}{0.7} = 1\ \mathrm{s}$$

**생성물 비.** 매 순간 $\dfrac{d[B]}{dt} = 2k_b[A]$, $\dfrac{d[C]}{dt} = k_c[A]$ (B는 계수 2). 비는 시간과 무관하게

$$\frac{[B]}{[C]} = \frac{2k_b}{k_c} = \frac{0.6}{0.4} = \frac32$$

**2t₁에서 [C].** $[A] = \alpha/4$이므로 반응한 A = $\tfrac34\alpha$. 그중 C로 간 분율은 $\dfrac{k_c}{k_b + k_c} = \dfrac47$:

$$[C] = \frac34\alpha \times \frac47 = \frac{3\alpha}{7}$$

(검산: A 보존 $\alpha = [A] + \tfrac12[B] + [C] = \tfrac{\alpha}{4} + \tfrac12\cdot\tfrac{9\alpha}{14} + \tfrac{3\alpha}{7}$ = α ✓)

**채점 포인트·함정**

- [B]/[C]에서 **계수 2**(A → 2B)를 빠뜨리면 3/4이 됩니다.
- 평행 반응의 반감기는 $k$의 **합**으로 정해집니다.

- (나) 오류: 이산화탄소가 물에 녹는 과정은 **흡열 과정 → 발열 과정**으로 수정.

<div class="key" markdown="1">

**공식·핵심 개념**

- 헨리 법칙: $C = k_HP_{\text{gas}}$ (부분 압력에 비례)
- 기체 용해는 발열 → 온도↑ 용해도↓ (르샤틀리에)
- 2022 개정 [물질과 에너지], 중학교 '물질의 성질' 관통개념: 입자 모형

**헨리 법칙**: 일정 온도에서 기체의 용해도는 그 기체의 **부분 압력**에 비례($C = k_H P_{\text{gas}}$). 질소 기포 속 CO₂의 부분 압력은 0이므로, 용액의 CO₂가 기포로 계속 빠져나갑니다(가스 스트리핑).

**온도의 영향.** 기체가 녹는 과정은 분자가 용매에 붙잡히며 에너지를 내놓는 **발열** 과정($\Delta H < 0$)입니다. 르샤틀리에 원리에 따라 온도가 높아지면 역방향(기체 방출)으로 평형이 이동 → 용해도 감소. 결론("온도가 높으면 용해도 감소")은 맞고 근거의 "흡열"만 틀렸습니다.

**채점 포인트·함정**

- ㉢의 관통개념은 3가지 이상(상대적 거리, 배열의 불규칙성, 운동성)을 씁니다.

## A형 9번 · 착물 형성이 있는 용해도 {#a9}

<img class="q" src="img/A09.png" alt="A형 9번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★★☆☆)

- 전하 균형식: $[\mathrm{M^+}] + [\mathrm{H^+}] = [\mathrm{OH^-}] + [\mathrm{X^-}] + [\mathrm{MX_2^-}]$
- 질량 균형식(수용액 I): $[\mathrm{M^+}] = [\mathrm{X^-}] + [\mathrm{MX_2^-}]$
- 용해도: $S = K_{sp}\left(\dfrac{1}{[\mathrm{X^-}]} + \dfrac{1}{K_1} + \dfrac{[\mathrm{X^-}]}{K_1K_2}\right)$
- 최소 용해도: $[\mathrm{X^-}] = \sqrt{K_1K_2}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 전하 균형식, 질량 균형식 세우기
- 용해도 $S$ = 녹은 M의 모든 화학종 합
- 착물 형성: 공통 이온 효과 vs 착물 효과 → 최솟값 $dS/d[X^-] = 0$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 체계적 평형 처리(전하·질량 균형)는 분석화학에서 나오지만 착물 용해도 최솟값까지는 드뭅니다. 균형식 쓰기는 꼭 연습하세요.

</div>

**질량 균형.** MX가 녹으면 M과 X가 1 : 1로 나오므로 (M 전체) = (X 전체):

$$[\mathrm{M^+}] + [\mathrm{MX}] + [\mathrm{MX_2^-}] = [\mathrm{X^-}] + [\mathrm{MX}] + 2[\mathrm{MX_2^-}] \;\Rightarrow\; [\mathrm{M^+}] = [\mathrm{X^-}] + [\mathrm{MX_2^-}]$$

**용해도 = 녹아 있는 M의 모든 형태의 합.** 각 화학종을 $K_{sp}$와 $[X^-]$로 나타내면

- $[\mathrm{M^+}] = \dfrac{K_{sp}}{[\mathrm{X^-}]}$
- $[\mathrm{MX}] = \dfrac{[\mathrm{M^+}][\mathrm{X^-}]}{K_1} = \dfrac{K_{sp}}{K_1}$
- $[\mathrm{MX_2^-}] = \dfrac{[\mathrm{MX}][\mathrm{X^-}]}{K_2} = \dfrac{K_{sp}[\mathrm{X^-}]}{K_1K_2}$

**최솟값.** $\dfrac{dS}{d[\mathrm{X^-}]} = K_{sp}\left(-\dfrac{1}{[\mathrm{X^-}]^2} + \dfrac{1}{K_1K_2}\right) = 0 \Rightarrow [\mathrm{X^-}] = \sqrt{K_1K_2}$. NaX를 조금 넣으면 공통 이온 효과로 S 감소, 더 넣으면 MX₂⁻ 착물 형성으로 S 증가 → 그 사이에 최소.

**채점 포인트·함정**

- $K_1, K_2$는 **해리** 상수입니다(형성 상수가 아님). 식에서 $K$가 분모로 들어가는 이유입니다.
- 전하 균형식에서 MX₂⁻의 전하 계수는 1입니다.

## A형 10번 · 수소 원자 1s의 정규화와 기대치 {#a10}

<img class="q" src="img/A10.png" alt="A형 10번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★★☆☆) $N = \left(\dfrac{1}{\pi a_0^3}\right)^{1/2}$, $\left\langle\dfrac1r\right\rangle = \dfrac{1}{a_0}$, $\langle V\rangle = -\dfrac{e^2}{4\pi\varepsilon_0 a_0}$, $\langle E_k\rangle = \dfrac{e^2}{8\pi\varepsilon_0 a_0}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 정규화 $\int|\psi|^2d\tau = 1$, $d\tau = r^2\sin\theta\,dr\,d\theta\,d\phi$
- $\int_0^\infty x^ne^{-ax}dx = \dfrac{n!}{a^{n+1}}$
- 비리얼 정리(쿨롱 퍼텐셜): $2\langle E_k\rangle = -\langle V\rangle$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 수소 원자 기대치 계산은 양자 영역에서 가끔 나옵니다. ⟨r⟩, 최대 확률 반지름으로 바꿔 나올 수 있습니다.

</div>

**정규화.** $\int|\Psi|^2 d\tau = 1$:

$$N^2\int_0^\infty r^2e^{-2r/a_0}dr\int_0^\pi\sin\theta\,d\theta\int_0^{2\pi}d\phi = N^2\cdot\frac{2!}{(2/a_0)^3}\cdot 2\cdot 2\pi = N^2\pi a_0^3 = 1$$

**⟨1/r⟩.**

$$\left\langle\frac1r\right\rangle = N^2\cdot 4\pi\int_0^\infty r\,e^{-2r/a_0}dr = \frac{4}{a_0^3}\cdot\frac{1!}{(2/a_0)^2} = \frac{1}{a_0}$$

**⟨V⟩, ⟨E_k⟩.**

$$\langle V\rangle = -\frac{e^2}{4\pi\varepsilon_0}\left\langle\frac1r\right\rangle = -\frac{e^2}{4\pi\varepsilon_0a_0}, \quad \langle E\rangle = -\frac{e^2}{8\pi\varepsilon_0a_0}$$

$$\langle E_k\rangle = \langle E\rangle - \langle V\rangle = \frac{e^2}{8\pi\varepsilon_0a_0}$$

비리얼 정리($2\langle E_k\rangle = -\langle V\rangle$)와 일치합니다.

**채점 포인트·함정**

- 부피 요소의 $r^2$와 각도 적분 $4\pi$를 빠뜨리기 쉽습니다.
- 정적분 공식 $\int_0^\infty x^n e^{-ax}dx = n!/a^{n+1}$에서 $a = 2/a_0$입니다(지수에 2가 붙음).

## A형 12번 · 역상 액체 크로마토그래피 {#a12}

- 분리도 $R = \dfrac{\Delta t_R}{w_{평균}}$

$$t_R = t_M(1 + k): \quad t_A = 2.0 \times 6.0 = 12.0\ \text{분}, \quad t_B = 2.0 \times 21 = 42.0\ \text{분}$$

## B형 1번 · 페로브스카이트 구조 {#b1}

<img class="q" src="img/B01.png" alt="B형 1번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★☆☆☆) $r_{C^{2-}} = \dfrac{\sqrt2}{2}l - r$, ⓐ $= \dfrac{l}{\sqrt2\,l - 2r}$

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 단위세포 원자 수: 꼭짓점 ⅛, 면심 ½, 체심 1
- 페로브스카이트 ABX₃: A 꼭짓점, B 체심, X 면심
- 접촉: A–X 면대각선 ½, B–X 변 ½

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 결정 구조와 이온 반지름 관계는 2023 기출 이후 계속 나오는 무기 소재입니다. 허용 인자(tolerance factor)로도 변형될 수 있습니다.

</div>

**구조.** A²⁺ 꼭짓점(8 × ⅛ = 1), B⁴⁺ 체심(1), C²⁻ 면심(6 × ½ = 3) → ABC₃, 전하 +2 +4 −6 = 0 → **페로브스카이트**(CaTiO₃형).

**C²⁻ 반지름.** 꼭짓점 A와 면심 C는 면대각선 절반 거리에서 접합니다:

$$\frac{\sqrt2}{2}l = r + r_C \;\Rightarrow\; r_C = \frac{\sqrt2}{2}l - r$$

**B⁴⁺ 반지름.** 체심 B와 면심 C는 한 변 절반 거리: $\dfrac{l}{2} = r_B + r_C \Rightarrow r_B = \dfrac{l - \sqrt2 l + 2r}{2}$.

**ⓐ.**

$$\frac{r_C}{r_B} = \frac{\sqrt2 l - 2r}{l - \sqrt2 l + 2r} = \frac{1}{\dfrac{l}{\sqrt2 l - 2r} - 1} \;\Rightarrow\; ⓐ = \frac{l}{\sqrt2\,l - 2r}$$

**채점 포인트·함정**

- A–C 접촉은 **면대각선**, B–C 접촉은 **변**의 절반입니다.
- 분모를 $\frac{l}{\sqrt2 l - 2r} - 1$ 꼴로 만드는 변형 과정을 보여 줍니다.

## B형 2번 · EBT 지시약과 EDTA 적정 {#b2}

<img class="q" src="img/B02.png" alt="B형 2번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★☆☆☆) $1\times10^{-6}\ \mathrm{M} \le [\mathrm{M^{2+}}] \le 1\times10^{-4}\ \mathrm{M}$

<div class="key" markdown="1">

**공식·핵심 개념**

- 조건 형성상수 $K_f' = \alpha_{Y^{4-}}K_f$
- 지시약 변색: $0.1 \le [MIn]/[HIn] \le 10$

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — EDTA 적정은 분석화학의 대표 소재입니다. 당량점 pM 계산이나 지시약 선택 근거로 나올 수 있습니다.

**변색 범위.** pH 10에서 유리 지시약은 HIn²⁻. 두 평형을 곱하면

$$\mathrm{M^{2+} + HIn^{2-} \rightleftharpoons MIn^- + H^+}, \quad K = K_f K_{a3} = 1.0\times10^{-5}$$

$$\frac{[\mathrm{MIn^-}]}{[\mathrm{HIn^{2-}}]} = \frac{K_fK_{a3}}{[\mathrm{H^+}]}[\mathrm{M^{2+}}] = \frac{10^{-5}}{10^{-10}}[\mathrm{M^{2+}}] = 10^{5}[\mathrm{M^{2+}}]$$

0.1 ≤ 비 ≤ 10 → $10^{-6} \le [\mathrm{M^{2+}}] \le 10^{-4}$ M.

**지시약 적합성 확인.** 당량점에서 [MY] = 0.01 M(부피 2배), $[\mathrm{M^{2+}}] = \sqrt{[\mathrm{MY}]/K_f'} = \sqrt{0.01/10^8} = 1\times10^{-5}$ M → 변색 범위 안이므로 EBT가 적절합니다.

**질량 균형.** 당량점에서는 넣은 EDTA 전체 = M 전체. MY는 양변에 같이 있어 지워지고, 유리 M²⁺ = 착물을 만들지 않은 EDTA 모든 형태의 합. 종말점에서는 지시약에 붙은 M(MIn⁻)도 유리 금속 쪽에 더합니다.

**채점 포인트·함정**

- $K_f$와 $K_{a3}$를 결합해 [H⁺]가 들어간 비로 만드는 것이 핵심입니다.

## B형 7번 · M₃(CO)₁₂의 18전자 규칙, 등엽성, CO 진동 {#b7}

<div class="ans" markdown="1">

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 18전자 규칙: 금속 전자 + 리간드 전자 + M–M 결합 1개당 1
- 등엽성: d⁸ ML₄ ↔ CH₂, d⁹ ML₅ ↔ CH₃

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★☆</span> 높음** — 금속 카보닐 전자 수 세기와 CO 진동 대칭은 무기에서 자주 나옵니다. 등엽성은 최근 출제 빈도가 오르는 소재입니다.

</div>

**18전자 계산(M 하나).** 족 번호 $x$(중성 원자 전자 수) + CO 4개 × 2 = 8 + M–M 결합 2개 × 1 = 2 → $x + 10 = 18$ → $x = 8$. (전체: 3x + 24 + 6 = 54 = 18 × 3)

**등엽성.** M(CO)₄는 d⁸ ML₄ 조각(팔면체에서 리간드 2개가 빠짐) — 전자 2개가 든 프런티어 오비탈 2개 → **CH₂**(탄소의 sp² 오비탈 2개에 전자 2개)와 등엽. 그래서 Os₃(CO)₁₂ ↔ 사이클로프로페인 (CH₂)₃, M(CO)₄ + CH₂ → H₂C=M(CO)₄.

**CO 신축 진동의 가역 표현.** 움직이지 않는 CO 수를 셉니다(z축 = C₃, M₃ 평면 = σh).

| D₃h | E | 2C₃ | 3C₂ | σh | 2S₃ | 3σᵥ |
|---|---|---|---|---|---|---|
| Γ_CO | 12 | 0 | 0 | 6 | 0 | 2 |

σh: 평면 안 6개(적도 CO), σᵥ: 그 평면 위 M의 축 CO 2개. 축소 공식으로 $2A_1' + A_2' + 3E' + A_2'' + E''$ (차원 2+1+6+1+2 = 12 ✓). IR 활성은 x, y(E′), z(A₂″) → **3E′ + A₂″**.

**채점 포인트·함정**

- M–M 결합 전자를 세지 않으면 족이 10이 됩니다.

## B형 10번 · 실제 기체의 엔탈피·엔트로피 변화 {#b10}

<img class="q" src="img/B10.png" alt="B형 10번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★★☆☆) $\Delta H_1 = 0.1$ J, $\Delta H_2 = 15000$ J, $\Delta S_{계} = 50.0\ln2\ \mathrm{J/K}$ (≈ 34.7 J/K)

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- $dH = C_PdT + V(1 - \alpha T)dP$
- $\pi_T = T(\partial P/\partial T)_V - P$
- $C_P - C_V = (\pi_T + P)(\partial V/\partial T)_P$
- 등압: $\Delta S = C_P\ln(T_2/T_1)$

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★☆☆</span> 보통** — 열역학 관계식을 상태방정식에 적용하는 유형은 모의고사 1회 A형 8번과 같은 계열입니다. 형태만 바꿔 반복 출제됩니다.

</div>

**과정 (가): 등온, 압력 변화.** $dT = 0$이므로 $dH = V(1 - \alpha T)dP$. 상태식 $V = \dfrac{nRT}{P} + nb$에서 $\left(\dfrac{\partial V}{\partial T}\right)_P = \dfrac{nR}{P}$:

$$V(1 - \alpha T) = V - T\left(\frac{\partial V}{\partial T}\right)_P = \frac{nRT}{P} + nb - \frac{nRT}{P} = nb$$

$$\Delta H_1 = nb\,\Delta P = 1 \times 0.001\ \mathrm{L} \times 1\ \mathrm{bar} = 0.001\ \mathrm{L\,bar} = 0.1\ \mathrm{J}$$

**과정 (나): 등압, 온도 변화.** 먼저 $\pi_T = T\left(\dfrac{\partial P}{\partial T}\right)_V - P = \dfrac{nRT}{V - nb} - P = 0$.

$$C_P = C_V + (0 + P)\frac{nR}{P} = C_V + nR = 41.7 + 8.3 = 50.0\ \mathrm{J/K}$$

$$\Delta H_2 = C_P\Delta T = 50.0 \times 300 = 15000\ \mathrm{J}, \quad \Delta S = \int_{300}^{600}\frac{C_P}{T}dT = 50.0\ln2\ \mathrm{J/K}$$

**채점 포인트·함정**

- 단위 환산: 1 bar·L = 100 J (자료의 1 bar = 10² J/L).
- 이 기체는 인력 항이 없어 내부 압력 $\pi_T = 0$ → $C_P - C_V = nR$ 그대로입니다.

## B형 11번 · 착물·침전이 있는 전지 전위 {#b11}

<img class="q" src="img/B11.png" alt="B형 11번 문항">

<div class="ans" markdown="1">

**정답** (답지 난이도 ★★★☆☆) $E_{전지}(1) = -0.90$ V, $E_{전지}(2) = -0.84$ V, $E_{전지}(3) = -1.11$ V

</div>

<div class="key" markdown="1">

**공식·핵심 개념**

- 네른스트: $E = E^\circ - \dfrac{0.060}{n}\log Q$
- 착물 형성·침전 → 유리 이온 농도 변화 → 전위 변화
- 한정 반응물 먼저 처리 후 남은 농도로 계산

</div>

<div class="odds" markdown="1">

**2027 출제 가능성 <span class="stars">★★★★★</span> 매우 높음** — 전기화학과 평형(착물·Ksp)을 묶는 계산은 분석화학 고빈도 유형입니다. 2027에도 형태를 바꿔 나올 가능성이 매우 높습니다.

</div>

**전지 전위 = E(오른쪽, B) − E(왼쪽, A)**, $\dfrac{2.303RT}{F} = 0.060$ V.

**(1)** $E_B = -0.13 - \dfrac{0.060}{2}\log\dfrac{1}{0.10} = -0.16$ V, $E_A = 0.80 - 0.060\log\dfrac{1}{0.10} = 0.74$ V → $E = -0.90$ V.

**(2) 왼쪽에 S₂O₃²⁻ 0.18 mol.** A⁺ 0.10 mol이 S₂O₃²⁻ 2개씩 필요한데 0.18 mol뿐 → 착물 0.09 mol, **A⁺ 0.01 mol 남음**(Kf가 커서 S₂O₃²⁻는 거의 다 소비). $E_A = 0.80 - 0.060\log\dfrac{1}{0.01} = 0.68$ V → $E = -0.16 - 0.68 = -0.84$ V.

**(3) 오른쪽에 NaI 0.30 mol.** BI₂ 침전으로 I⁻ 0.20 mol 소비 → [I⁻] = 0.10 M 남음.

$$[\mathrm{B^{2+}}] = \frac{K_{sp}}{[\mathrm{I^-}]^2} = \frac{10^{-10}}{10^{-2}} = 1.0\times10^{-8}\ \mathrm{M}$$

$$E_B = -0.13 - 0.030\log\frac{1}{10^{-8}} = -0.37\ \mathrm{V}, \quad E = -0.37 - 0.74 = -1.11\ \mathrm{V}$$

**채점 포인트·함정**

- (2)에서 착물이 다 생긴다고 보고 [A⁺]를 Kf로 구하면 틀립니다 — S₂O₃²⁻가 **부족**합니다.
- B는 2전자 반응이므로 $0.060/2 = 0.030$을 씁니다.
- 음수 전위는 그림의 연결 방향(오른쪽 − 왼쪽)대로 쓴 값입니다. 실제 자발 반응은 A⁺ 환원, B 산화입니다.
