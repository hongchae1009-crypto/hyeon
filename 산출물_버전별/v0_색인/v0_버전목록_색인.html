질문별·버전별 산출물 목록 (유기화학 기출변형 프로젝트)

모든 버전은 MD · HTML · PDF(A4) 세 형식으로 제공한다. 폴더 이름의 v번호는 산출 순서를 나타낸다. 과거 버전(v3·v5)은 git 기록의 해당 시점 커밋에서 그대로 다시 빌드한 것이다(내용은 당시와 동일).

1. 질문 → 산출물 대응표

# 질문(요약) 그때의 답변·조치 산출 버전
① 교재 PDF 4개(Klein 7–11, 12–14, 15–19, 20–23장) 업로드. "논문·반응 정리(이미지화), 기출변형 제작, 기출 연도·번호·소스·해설 표기" 스캔 PDF 판독 → 장별 인용 논문 추출 착수. 기출 파일은 받는 대로 반영하기로 함 v1 교재 인용 논문 추출본
② 교재 1–6장 + 2026A·B, 2024A·B 기출 업로드 1–6장 추출 추가, 기출 유기 문항 정리 시작 v1 보강, v2 착수
③ 2025A·B, 2023A·B, 2022B 업로드 기출 카탈로그에 추가 v2
④ 2022A, 2020A·B, 2021A·B 업로드 기출 카탈로그에 추가 v2
⑤ 2018A·B, 2019A·B 업로드 2018–2021 카탈로그를 별도로 작성 v2
⑥ 2016A·B, 2017A·B 업로드 2014–2017 카탈로그 착수 v2
⑦ 2014A·B, 2015A·B 업로드 2014–2017 카탈로그 완성 → 기출 유기 66문항 확보 v2 기출 유기 문항 카탈로그
⑧ "A4 프린트 가능한 pdf파일과 html파일로 생성해줘" A4 2단 기출 양식, RDKit SVG 구조식, PDF 출력 파이프라인 구축 → 견본 문항 1개 v3 A4 출력 견본
⑨ "최근 트렌드/영역별 중요도, 노벨 화학상 반영해서 엄선" 영역별 빈도 분석, 노벨상 연계 방침, 선별 원칙 수립(첫 답변은 영어) v4 출제 방향 계획서
⑩ "한글로 대답해줘" 같은 내용을 한국어로 다시 보고 v4 (한국어 통합본)
⑪ "중요도 우선순위 다 반영해서 66문제 만들어줘" 기출 66개 슬롯을 중요도·최신순으로 6회×11문항에 배정, 영역별 출제 에이전트 7개 투입 v5 66문항 초판
⑫ "기출 1:1 아니어도 되니 중요도 순서로 중요 반응 위주로" 방침 변경(저가치 기출 자리는 같은 영역의 핵심 반응으로 교체, '유형' 표기). A2 중복 4문항 교체 → 초판 완성 → 3중 검수 → 최종 v5(A2 원안 포함) → v6 최종본
⑬ "질문할 때마다 나온 산출물을 버전별로 빠짐없이 html·md·pdf로" 이 아카이브 v7 이 목록

2. 버전별 파일

v1 — 교재 인용 논문 추출본 (질문 ①·②)

  • v1_교재인용논문_추출본_영문원본 (당시 산출물, 영어) · v1_교재인용논문_추출본_한국어판 (질문 ⑬에서 번역 추가) — Klein 1~23장 각 장 끝 「참고문헌」과 각주가 달린 문제를 대응시킨 원자료. 장 요약, 문헌, 반응(SMILES), 질문, 예상 답과 신뢰도 포함.
  • 구성: 1–6장 / 7–9장 / 9장 후반·10–12장 / 13–14장 / 15–19장 / 20–23장.

v2 — 기출 유기 문항 카탈로그 (질문 ②~⑦)

  • v2_기출유기문항_카탈로그 — 2014~2026학년도 1차 전공A·B의 유기 문항 66개. 각 문항의 원문 발문, 반응식(SMILES), 자료, 직접 푼 정답, 핵심 개념을 담았다.

v3 — A4 출력 견본 (질문 ⑧)

  • v3_견본_문제지, v3_견본_정답해설 — 기출 양식(표지·2단·배점·면수)과 해설 양식을 검증하려고 만든 견본 문항 1개(Wittig → Sharpless).

v4 — 출제 방향 계획서 (질문 ⑨·⑩)

  • v4_출제방향_계획서 — 영역별 빈도·중요도, 최근 경향, 노벨상 연계표, 선별 원칙, 당시 진행 보고.

v5 — 66문항 초판, 검수 전 (질문 ⑪·⑫)

  • v5_66문항_배정표 — 회-번, 배점, 중요도, 영역, 참고 기출, 소스 논문, 노벨상, 변형 포인트.
  • v5_문제지_초판, v5_정답해설_초판, v5_논문반응_정리집
  • v5부록_A2원안_문제지, v5부록_A2원안_정답해설 — A1과 소재가 겹쳐 교체되기 전의 A2 영역 7문항 원안.

v6 — 최종본, 검수 반영 (질문 ⑫ 최종)

  • v6_66문항_배정표, v6_검수수정내역(초판 대비 14문항 수정 내역)
  • v6_문제지_최종, v6_정답해설_최종, v6_논문반응_정리집 (정리집 내용은 v5와 동일)

v7 — 이 목록 (질문 ⑬)

  • v0_버전목록_색인

3. 형식 안내

  • PDF: A4 인쇄용 최종 조판본.
  • HTML: 브라우저에서 열면 A4로 자동 배치된다. 인쇄(Ctrl+P)하면 PDF와 같은 결과가 나온다. 시험지는 자바스크립트로 2단 배치된다.
  • MD: 텍스트 편집·검색용. 구조식·스펙트럼 SVG는 각 버전 폴더의 assets/에 분리되어 이미지 링크로 들어 있다(GitHub 등에서 보인다). 시험지 MD는 회차별·문항별로 정리되어 있다.
